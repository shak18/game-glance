# Volunteer tester invitation

## Short version

**Help test Game Glance on your device**

I’m looking for volunteers to help test new Game Glance features and catch device-specific bugs before wider releases. Different handhelds, operating systems, screen sizes, and docked setups are all useful.

Testing is entirely optional. You do not need Discord, and you do not need to pay or support the project financially. You can keep using the normal stable releases exactly as before.

If you’d like to help, add your device and OS details here:
https://github.com/michpalm/game-glance/issues/new?template=tester-interest.yml

When a test matches your setup, I’ll post the build, what to test, and how to report the result. Thanks for helping make the plugin more reliable across devices!

## Release-post version

**Volunteer testing wanted**

I’m building a small opt-in group to test upcoming Game Glance changes on real devices. I’m particularly interested in different handhelds, SteamOS-like distributions, screen sizes, and handheld/docked use.

There’s no obligation to test every release, no paid tier, and no need to join Discord. The stable plugin remains free and bug reports are welcome from everyone.

Opt in with your device and OS here: https://github.com/michpalm/game-glance/issues/new?template=tester-interest.yml
