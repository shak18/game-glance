# Game Glance 3.1.0-rc.1 (pre-release)

A test build of the new open transition from Home to a game's page. Not for the Decky store, and the built-in updater
ignores it: install it from the zip on this release page (Decky → Settings → Developer → **Install plugin from ZIP**).

- **A new open transition.** Opening a game from Home now moves Home's own elements into place, instead of scaling up
  the wide card. The hero art stays put; the title or logo, the Play row, the buttons and the info cards slide to their
  places on the game page. The description and the HowLongToBeat numbers appear as the page opens.
- **Home is ready to open.** The description and HowLongToBeat numbers of games in the recent row are fetched in the
  background, so the open has them.
- **Faster cycling.** Holding or quickly pressing L1/R1 or the d-pad keeps the screen steady, and the selected card
  widens once the presses stop.
- **Play from.** Home's Play pill has Steam's "Play from" arrow for games installed on more than one device.
- **Back to Home.** Pressing B on a game page brings Home back at once, with no dark flash.

Known gaps in this build: a game with no hero art and reinstalling Game Glance during an open are not yet checked on
the device.
