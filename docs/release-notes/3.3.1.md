# Game Glance 3.3.1

A fix for the game page's cards on handhelds. Update from Quick Access → Game Glance → Updates.

- **The cards no longer overlap.** On the Steam Deck, the ROG Ally and other handhelds, the HowLongToBeat card was
  wider than its space and covered the end of the game's description. When a game opened from Home, the card also
  jumped left as the open transition handed over to the page. Both are fixed (#53).
- **Narrower cards.** The HowLongToBeat card is now just wide enough for its times, without the empty space after
  100%, and the description card is a little narrower to match. The game's art shows between them.

Thanks to NjDADE for the report and the video.
