# Game Glance 3.1.2-wide-screen.1 (pre-release)

A test build for **ultrawide and other screens wider than 16:9** (21:9, 32:9, desktop monitors). It's 3.1.1 plus the
wide-screen fix below. Not for the Decky store, and the built-in updater ignores it: install it from the zip on this
release page (Decky → Developer → Install plugin from ZIP). When 3.1.2 is released, the updater offers it as usual.

- **Spotlight Home fits wide screens.** On a screen wider than 16:9, the games row was half hidden behind Steam's button
  legend and the What's new / Friends / Recommended tabs were off-screen. Home now scales by the screen's height on
  those screens and uses the extra width as side room, so the whole Home fits.
- **The game page fits too.** The page scales the same way, so the open transition from Home still lands on it. On a
  wide screen the two cards stay compact (the description at the left, HowLongToBeat at the right edge) and the
  game's art shows between them. The Clean look fits as well.
- **16:9 and 16:10 screens are unchanged**, including the Steam Deck, the ROG Ally and 1080p/4K TVs.

Tested on a ROG Xbox Ally docked to a TV, with Steam's window emulated at 21:9 and 32:9. It hasn't been tested on a
real ultrawide monitor yet. That's what this build is for. If something doesn't fit, please open an issue with your
screen's resolution and a screenshot.
