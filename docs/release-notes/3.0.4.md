# Game Glance 3.0.4

This release brings full touch, mouse, and swipe support across Spotlight Home and Library, brings Spotlight Home's full-screen zoom animation to the game library, introduces multi-collection tabs navigation, and adds live artwork reloading.

## What's New

### 🏠 Upstream Core Stability
- **Home recovers from an error.** If Spotlight Home hits an error that used to break the Home screen (React error #130, reported on SteamOS), Steam's own Home now shows instead, and the screen keeps working. Turn Spotlight Home off in Quick Access as before if you want Steam's Home all the time.
- **A log for reports.** Game Glance writes `game-glance.log` to `~/homebrew/logs/Game Glance/`. It records each start-up and any recovered error. When you report a problem, attach that file.

### 👆 Full Touch, Mouse & Wheel Navigation
- **Spotlight Home Carousel:**
  - Drag and swipe with natural momentum physics, or scroll horizontally with the mouse wheel.
  - Tapping an unfocused card smoothly centers and focuses it; a second tap launches the game.
  - Drag-release protection ensures swiping never accidentally launches a game.
  - Carousel pointer interactions are cleanly disabled while the bottom feed (What's new / Friends / Recommended) is open.
- **Spotlight Library Grid & Top Ribbon:**
  - Full touch drag, swipe flick with momentum decay, and mouse wheel scrolling across both the game grid and category bar.
  - Active focus reconciliation keeps controller and keyboard focus in sync with touch/mouse scroll positions.

### 🎬 Seamless Zoom-to-Fullscreen Animation in Library
- Selecting a game in the library (via tap, card click, controller A button, or Details/Poster in the inspector) now smoothly expands the banner into full screen before opening the game details page.
- Matches Spotlight Home's signature 480ms easing transition for complete visual consistency across views.

### 📂 Multi-Collection Tabs Ribbon
- When viewing a collection, the top bar now displays **all collections as scrollable tabs** with individual game counts and active indicators.
- Seamlessly swipe, mouse-scroll, or tap between collections, or cycle through them with **L1 / R1** bumpers.
- A fixed **‹ COLLECTIONS [B]** action on the top left lets you quickly return to the collections overview grid.

### 🎨 Live Steam Artwork Reload & Cache-Busting
- Added **Reload Steam artwork** in Quick Access (`...` → Game Glance → Data).
- Directly probes custom SteamGridDB image paths and busts Steam CEF image caching, immediately updating newly assigned heroes, logos, and banners without needing to restart Steam.

---
**Installation:** Download `game-glance.zip` below and install via Decky Loader (Settings → Developer → Install plugin from ZIP), or update directly inside Game Mode from Quick Access → Game Glance → Updates.
