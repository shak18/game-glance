# Game Glance 3.0.5

This release introduces comprehensive visual customization controls, modular Spotlight Home feed sections (including an ultra-clean feedless mode), direct Library Collection shortcuts on Home, accessibility and scale protections against Steam Large Text mode, full controller gamepad support for the library zoom transition, critical stability fixes for PC handhelds and custom Linux distributions (such as CachyOS and Bazzite), and integrates upstream sound effects and Space Required stats.

## What's New

### 🔊 Sounds & Space Required (Upstream Core)
- **Sounds when you open and start a game.** Opening a game from Home plays Steam's own sound for going into a game's page, and Play plays Steam's game-start sound, as on the game page.
- **Space Required for Steam games.** A Steam game that isn't installed shows the space it needs, labelled "Space Required" in Steam's language, on Home (next to Played) and on the game page.

### 🏠 Modular Spotlight Home Feed Sections & Ultra-Clean Mode
- **Individual Section Toggles**: Added toggles under Spotlight Home settings to independently enable or disable each bottom feed section:
  - **What's New section** (patch notes, events, and update announcements)
  - **Friends section** (friend activity and presence)
  - **Recommended section** (play next recommendations and wishlist sales)
  - **Collections section** (library collection shortcuts)
- **Ultra-Clean Feedless Mode**: When all four feed sections are toggled off, Spotlight Home enters a clean carousel mode. The bottom sheet unmounts completely and downward scrolling is disabled, leaving an immaculate, distraction-free hero carousel.

### 📚 Library Collection Shortcuts on Home
- Added a dedicated **Collections** tab/shelf in Spotlight Home's bottom feed.
- Collection cards display custom artwork from the collection's top game, total game count pills, and collection title.
- Activating a collection card opens directly into that collection within Spotlight Library (or Steam's native collection view).
- Filtered out the redundant "Locally Installed Games" collection so only custom user collections and Favorites are presented as quick shortcuts.

### 🎮 Controller 'A' Button Zoom Animation in Spotlight Library
- Fixed an issue where pressing the gamepad **A** button on a focused game in Spotlight Library would skip the zoom animation and transition immediately.
- Gamepad activations now track the focused card element coordinates and launch the smooth 480ms zoom-into-fullscreen transition, matching touch and mouse interactions.

### ✨ New "Visuals & Effects" Settings Section & Zoom Transition Toggle
- Added a dedicated **Visuals & Effects** section in the Quick Access settings menu.
- Added **Zoom into full screen** toggle (enabled by default): users who prefer instant navigation can now disable the zoom animation entirely across both Spotlight Home and Spotlight Library.

### 🌑 "Unhighlight Uninstalled Games" Option
- Added a new **Unhighlight uninstalled games** setting under Visuals & Effects (disabled by default).
- When enabled, games not currently installed on your device receive a subtle, desaturated neutral gray accent (`#707784`) instead of vibrant colored highlights.
- In addition, gallery artwork for uninstalled games is automatically rendered in sleek GPU-accelerated grayscale (85% on posters/hero, 65% on logos), making installed vs. uninstalled titles instantly distinguishable.

### 📐 Immune Proportional Scaling & Steam "Large Text" Protection
- Redesigned collection cards to modern **1:1 square tiles** (`aspect-ratio: 1 / 1`), preventing card overlap when large system fonts or accessibility text scaling is active.
- Collection titles support up to 2 lines of text with clean word-wrapping and ellipsis (`...`) clipping for long names, accompanied by badge pills indicating the game count.
- Locked library typography, navbar, collection cards, and inspector against Steam's system font / accessibility Large Text mode, preventing layout breakage and card overlap.
- Proportional scale formula matching handheld and TV/docked resolutions with refined poster dimensions and centered circular action button prompts.

### 🎯 Spotlight Library Navigation & Grid Fixes
- Eliminated stale index closures and cross-tab card memoization jumps when navigating or switching categories.
- Fixed an issue where rapid category switching could cause card focus to land on an unexpected item.

### 🛡️ Critical Fix for PC / CachyOS & Custom Decky Router Environments
- Resolved a crash on startup/navigation: `TypeError: Class constructor LibraryErrorBoundary cannot be invoked without 'new'`.
- Refactored `LibraryErrorBoundary`, `HomeErrorBoundary`, and `ErrorBoundary` into hybrid callable constructor components compatible with environments where Decky Loader's router patches invoke component factories directly without `new`.
- Fixes library screen crashes and black screen lockups reported on CachyOS, Bazzite, and desktop Decky setups.

### 🕹️ Fix Steam Game Demos Not Appearing in Library & Home
- Fixed an `app_type` categorization issue where downloaded Steam game demos (`app_type: 8`) and betas were mistakenly matched against soundtrack filters instead of being recognized as playable games.
- Game demos (and Steam playtests/betas) now properly appear across all relevant library categories (Installed, All Steam Games, Great on Deck, Favorites, Collections) as well as Spotlight Home recents.
