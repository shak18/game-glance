# Game Glance 3.1.2

Spotlight Home and the game page now fit screens wider than 16:9. Update from Quick Access → Game Glance → Updates.

- **Spotlight Home fits wide screens.** On a screen wider than 16:9 (21:9, 32:9, desktop monitors), the games row was
  half hidden behind Steam's button legend and the What's new / Friends / Recommended tabs were off-screen. Home now
  scales by the screen's height on those screens and uses the extra width as side room, so the whole Home fits.
- **The game page fits too.** The page scales the same way, so the open transition from Home still lands on it. On a
  wide screen the two cards stay compact (the description at the left, HowLongToBeat at the right edge) and the
  game's art shows between them. The Clean look fits as well.
- **16:9 and 16:10 screens are unchanged**, including the Steam Deck, the ROG Ally and 1080p/4K TVs.

Thanks to everyone who tested the wide-screen pre-release on their ultrawide screens.
