# Game Glance 3.0.7

A fix for Spotlight Home with SteamGridDB. Coming from 3.0.x, update from Quick Access → Game Glance → Updates.

- **SteamGridDB.** With SteamGridDB's "Square capsules" or "Uniform featured" setting on, Home could break with a
  React error ("Class constructor RouteGuard cannot be invoked without 'new'" in 3.0.4 to 3.0.6, React error #130
  before), depending on which plugin loaded first. Both plugins now patch Home side by side. Thanks to
  [@KnifeFed](https://github.com/KnifeFed) for tracking it down and sending the fix (#18).
