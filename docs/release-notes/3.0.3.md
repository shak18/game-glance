# Game Glance 3.0.3

A small fix to the built-in updater. Coming from 3.0.x, update from Quick Access → Game Glance → Updates.

- **Pre-releases are ordered correctly.** A pre-release such as 3.1.0-rc.1 is older than the release with the same
  numbers (3.1.0), so the update to 3.1.0 is offered to anyone on the pre-release. Before, it showed "up to date".
