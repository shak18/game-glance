# Game Glance 3.1.1-rc.1 (pre-release)

The 3.1.0 test build with the Home fix from 3.0.4. Not for the Decky store, and the built-in updater ignores it: install
it from the zip on this release page.

- **Home recovers from an error.** If Spotlight Home hits an error that used to break the Home screen (React error #130,
  reported on SteamOS), Steam's own Home now shows instead, and the screen keeps working.
- **A log for reports.** Game Glance writes `game-glance.log` to `~/homebrew/logs/Game Glance/`. It records each start-up
  and any recovered error. Attach that file when you report a problem.

Everything from 3.1.0-rc.1 is still in this build: the new open transition from Home to the game page, the description
and HowLongToBeat numbers drawn during the open, and the other changes listed in 3.1.0-rc.1's notes.
