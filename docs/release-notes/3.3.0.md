# Game Glance 3.3.0

Home's games row moves like Steam's own. Update from Quick Access → Game Glance → Updates.

- **A row like Steam's Home.** The last played game is the wide card. Left and Right move the selection toward the
  middle of the screen; from there the row scrolls and keeps it centred, the games before it faded on the left. The
  old row, where the selected game widens at the left edge, is still there: Quick Access → Game Glance → **Games row
  style** → Spotlight.
- **Games you have not installed are grey.** In the row, a game not installed on this device is grey until you select
  it, as in Steam's library. Non-Steam shortcuts are never greyed. A game installed only on another PC (for Remote
  Play) counts as not installed here.
- **Demos.** Demos in your recent games or the chosen collection now show in the row, marked DEMO (in Steam's own
  word, next to NEW on the wide card, under it on the others), and in the screensaver.
